# Lizenzstatus

Für den eigenen Wachwerk-Code, das Projektlogo und die Projektgrafiken wurde in diesem Paket keine neue Open-Source-Lizenz festgelegt. Die Wahl einer Lizenz bleibt beim Projektinhaber. Dieses Repository wird daher nicht als MIT-, Apache- oder anderweitig offen lizenziertes Gesamtprojekt bezeichnet.

Vor einer Freigabe zur allgemeinen Weiterverwendung sollte der Projektinhaber eine passende Lizenz auswählen und deren vollständigen Text als `LICENSE` ergänzen. Ein öffentliches GitHub-Repository allein ersetzt diese Entscheidung nicht. [GitHub erklärt die Lizenzwahl](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

Die Lizenzen der eingebundenen Drittanbieter-Komponenten gelten unabhängig davon. Siehe [Drittanbieter-Hinweise](THIRD_PARTY_NOTICES.md).
